# ShipTrack – Shipment Tracking Application

ShipTrack is a responsive shipment tracking web application built using React and TypeScript. It provides users with a simple interface to track shipments, view delivery information, and explore checkout options.

## Features

- Shipment tracking using Air Waybill (AWB) numbers
- Shipment status display
- Sample shipment data
- Checkout interface
- Cash on Delivery and prepaid payment options (demo interface)
- Pincode lookup using India Post API
- Responsive user interface
- LocalStorage-based shipment data

## Tech Stack

- React
- TypeScript
- CSS
- Vite
- LocalStorage
- India Post API

## Getting Started

Clone the repository:

```bash
git clone https://github.com/aliyasiddiqha55/shiptrack-app
```

Navigate to the project folder:

```bash
cd shiptrack-app
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
